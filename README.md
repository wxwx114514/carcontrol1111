# 小车蓝牙遥控 App（HC-05 / 经典 SPP）

配套单片机工程：`D:\fuckingCCS\projects\EX21-Car-L9110-Key`（键盘 + 蓝牙双控）。

- **方向盘**：拖动旋转，**不自动回正**，**0° 有吸附**（进 ±8° 直接归零 + 轻微振动，±18° 内减敏，模拟"卡位"）
- **前后滑块**：上 = 前进、下 = 后退，**松手保持位置**（不自动回零），带 10%/20% 刻度与百分比标注，0 附近有吸附
- **急停 / 回正** 按钮；退到后台自动发停车帧
- 不依赖任何第三方库、不需要 AndroidX，界面全部代码创建

## 一、没有 Android Studio 怎么出 APK（推荐）

1. 注册 GitHub 账号，新建一个仓库；
2. 把本目录（`CarControl`）里的所有文件推上去：**注意 `.github/workflows/build-apk.yml` 也要推**（这是云端编译脚本）；
3. 推上去后点仓库的 **Actions** → 左侧 `build-apk` → 等 3~5 分钟变成绿色；
4. 在这次的运行记录页面底部 **Artifacts** 里下载 `carcontrol-debug-apk.zip`，里面就是 `app-debug.apk`；
5. 传到手机安装（需要允许"安装未知来源应用"）。

以后改了代码，只要再 push 一次，就会自动重新编译。

> 备注：也可以在任何装了 Android Studio 的电脑上直接 `File → Open` 本目录，Gradle 会自动同步（本工程没有三方依赖，同步很快）。

## 二、手机端操作步骤

1. 系统设置 → 蓝牙 → 打开蓝牙 → 搜索 `HC-05` → 配对（PIN 通常是 `1234`，个别是 `0000`）；
2. 打开 App → 点 **连接** → 选那个 HC-05；
3. 顶部状态栏会显示 `已连接  V=…  W=…`；
4. 拖动方向盘 / 滑块开车；**急停** 按钮随时把速度和转向清零并发急停标志。

## 三、单片机接线（HC-05）

| HC-05 | MSP430F5529 | 说明 |
|---|---|---|
| VCC | 3V3 或 5V（按模块丝印） | 峰值约 40mA |
| GND | GND | **必须共地** |
| TXD | **P2.0** | 模块发、单片机收（**唯一的必需信号线**） |
| RXD | **P2.2** | 单片机发（可选，只用于自检/回显） |

串口参数：**9600 8N1**（HC-05 出厂默认，不要改）。

> 单片机上用的是**软件模拟串口**（`softuart.c`）：RX 必须放在 P1/P2 上
> （F5529 只有 P1、P2 支持引脚中断，软串口靠起始位下降沿中断启动），
> 所以不用芯片自带的 UART，也就不受引脚复用影响。

## 四、通信协议（10 字节，单向：手机 → 车）

| 偏移 | 内容 |
|---|---|
| 0 | `0xA5` 帧头 1 |
| 1 | `0x5A` 帧头 2 |
| 2 | 类型 `0x01` = 控制帧 |
| 3 | seq（0~255 循环，用于判丢包） |
| 4-5 | `v` int16 小端，-1000~1000（正 = 前进） |
| 6-7 | `w` int16 小端，-1000~1000（正 = 右转） |
| 8 | flags：bit0 = 刹车，bit2 = 急停 |
| 9 | 前 9 字节异或校验 |

发送频率 33Hz；单片机侧 **300ms 收不到有效帧就自动停车**。

## 五、想手动验证协议

用手机上的串口助手 App 连 HC-05，**发送模式切到 HEX（十六进制）**，一次发完这 10 个字节：

```
A5 5A 01 00 E8 03 00 00 00 15
```

含义：`v = 0x03E8 = 1000`（满速前进）、`w = 0`、无 flags、seq = 0。
校验 = A5^5A^01^00^E8^03^00^00^00 = **0x15**。

常用帧（校验都算好了，直接抄）：

| 动作 | 十六进制 |
|---|---|
| 满速前进 | `A5 5A 01 00 E8 03 00 00 00 15` |
| 半速前进 | `A5 5A 01 00 F4 01 00 00 00 0B` |
| 满速前进 + 半舵左转 | `A5 5A 01 00 E8 03 0C FE 00 E7` |
| 原地右转（满舵） | `A5 5A 01 00 00 00 E8 03 00 15` |
| 原地左转（满舵） | `A5 5A 01 00 00 00 18 FC 00 1A` |
| 停车（零速） | `A5 5A 01 00 00 00 00 00 00 FE` |
| 刹车 | `A5 5A 01 00 00 00 00 00 01 FF` |

串口助手别勾"发送新行/加 \r\n"（多出的 2 字节会被当噪声丢掉，但没必要）。
车应该满速前冲；**停止发送 300ms 后自动停车**——这条通了再上方向盘调手感。

## 六、手感调参位置

| 想要的效果 | 改哪里 |
|---|---|
| 方向盘行程变大/变小 | `SteeringWheelView.MAX_ANGLE`（默认 135°） |
| 0° 吸附更强/更弱 | `SteeringWheelView.SNAP_ZONE`（默认 8°）、`SOFT_ZONE`（18°） |
| 直线跑偏时留更多余量 | `SteeringWheelView.DEAD_ZONE`（默认 3°） |
| 滑块吸附范围 | `TickSliderView.SNAP_V`（默认 40‰） |
